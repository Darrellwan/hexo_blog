### n8n 是什麼？

n8n 是一套開源的自動化工具。
用拖拉節點的方式把不同服務串起來，一個節點負責一個動作。
串起來就是一條 workflow，取代原本要手動重複做的事。

n8n 跟 Zapier、Make 常被拿來比較。
兩者最大差別在兩點。
一是開源，可以自己架，不一定要綁在 SaaS 上。
二是計費邏輯不一樣：n8n 是照「整條流程跑一次」算錢，Zapier、Make 是照「步驟」（task）算錢。
細節下面費用那段會講。

### Cloud 還是自己架？

n8n 有官方 Cloud 版，也可以自己架伺服器跑 Community 版。
兩者怎麼選，看下面這張表：

| 比較項目 | n8n Cloud | 自己架（Community） |
|---|---|---|
| 費用 | 訂閱制，看方案 | 主程式免費，只付主機費 |
| 維護 | 官方負責 | 更新、備份、掛掉都要自己顧 |
| 適合誰 | 不想碰維運、想快點開始 | 想省錢、想完全掌控資料 |

台灣社群最常見的自架方式是用 Zeabur 一鍵部署，或是自己用 Docker 架。
兩種方式的教學都在[n8n 部署與設定](/n8n-deployment/)。

我自己的建議分兩種情況。
只是想先玩玩看、測試流程可不可行，用 Cloud 免費試用或 Zeabur 架一個最快，不用自己顧主機。
真的要跑正式業務，先估算一個月大概會跑幾次流程。
再回頭比較 Cloud 方案費用跟自架主機費用哪個划算。
估算量之前先看下面費用怎麼算那段。
n8n 計費邏輯跟其他自動化工具不太一樣，很多人一開始會抓錯量。

### 費用怎麼算？

n8n 算錢的單位是 execution。
一次 execution 就是整條 workflow 跑完一次，不管裡面串了幾個節點、處理多少筆資料，都算一次。
這跟 Zapier、Make 按步驟（task）計費是完全不同的邏輯。
流程節點越多但只需要跑一次的話，n8n 通常會划算不少。

Cloud 方案目前三種：

- **Starter**：€20/月（年繳），2,500 次 execution
- **Pro**：€50/月，10,000 次 execution
- **Business**：€667/月，40,000 次 execution

Starter 跟 Pro 都有免費試用可以先測，不用綁卡。
自己架 Community 版完全免費、開源，沒有 execution 上限，成本只有主機費。
這也是很多台灣用戶選自架的原因。

（以上為 2026 年 8 月官網實查，價格以官方為準）

### 第一個 workflow 做什麼？

裝好之後不用想太多，照這個順序上手就好：

1. 先從 [Webhook](/n8n-webhook/) 開始，搞懂外部服務怎麼把資料丟進 n8n，這是幾乎所有流程的起點
2. 接著串 [Google Sheets](/n8n-google-sheets-node/)，把抓到的資料存下來，這步最容易有成就感，因為馬上看得到結果
3. 台灣用戶通常第三步會想接 [LINE](/n8n-line-message-api/)，讓流程跑完直接推播通知自己，不用回頭盯畫面

這三步走完，n8n 的基本邏輯大概就懂了。
剩下就是照需求換節點，玩法很多，不用照本宣科。

### 學習路徑

新手：安裝 → Webhook → Google Sheets，先求流程跑得起來，不用一開始就求完美。

進階：開始碰 AI 相關的節點應用，再往自架部署鑽，部署教學一樣在[這裡](/n8n-deployment/)。

### 常見問題

**要會寫程式嗎？**
不用。n8n 節點大多用拖拉設定就能完成。
會一點 JavaScript 或 Python 在遇到複雜邏輯時會方便很多，但不是必要條件。
真的卡住，站內每篇節點教學都有實際設定截圖可以對照。

**n8n 真的免費嗎？**
Community 版免費、開源，自己架主機就好。
Cloud 版是訂閱制，Starter 跟 Pro 方案有不用綁卡的免費試用可以先測。

**跟 Make、Zapier 差在哪？**
最大差異是計費邏輯（按流程 vs 按步驟）跟能不能自架。
n8n 開源可以自己架，Make、Zapier 都是純 SaaS，沒得選。
長期跑量大的話這點差很多。

**版本更新這麼快，要怎麼跟？**
不用每版都追。
升級前看[n8n 功能更新](/n8n-update-log/)就好，我每版都會整理新功能跟要注意的地方，不用自己爬 release note。
